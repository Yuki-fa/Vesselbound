# データ・文言

シート駆動の文言とデータ反映規則を記録する。カードデータ、効果文、画面文言、ローカル内蔵CSVを変更するときに読むこと。

## 7. 画面の文言はシートから引く

**画面に出る固定の文言（見出し・ボタン・指示文・説明文）は
「テキストメッセージ」シートが唯一の出どころ。** コード側の文字列は
**シートを読めなかった時の予備**としてだけ持つ。新しい文言を足す時も必ずこの形にする。

| 出し方 | 使うもの | 置き場 |
| --- | --- | --- |
| JSからDOMへ書く | `textMessage(場面, 予備)` | `js/data/loader.js` |
| ボタン・見出しのラベル | `_uiLabel(場面, 予備)`（`textMessage` の薄い包み） | `js/engine/reward.js` |
| 決まった位置の枠見出し | `applySheetDomTitles()`（`SHEET_DOM_TITLES` に足す） | `js/engine/main.js` |
| CSSの `content:` | `applySheetCssTexts()` がカスタムプロパティへ入れ、`content:var(--title-xxx,"予備")` で読む | `js/engine/main.js` ＋ `index.html` |

- **シートの「場面」列は改行を含むことがある**
  （例：「編成、ショップ画面「旅の進捗」内」＋改行＋「通常時」）。
  `textMessage()` が空白・改行を無視して突き合わせるので、呼び出し側は1行で書いてよい。
- **本文の中の記号はシートの書式をそのまま使う。**
  `〜`＝塔の名前、`X`／`Y`＝数値（`_journeyCountdownHtml()`／オンラインの「選択完了 X/Y」）。
  コード側で「〜まであと」などの文をつなぎ直さない。
- 2段階選ぶアイテムの指示文は「「◯◯」使用時1」「使用時2」。1段階なら「「◯◯」使用時」。
  引き当ては `_itemUsePromptText()` が唯一の実装。
- **シートに行が無い文言はコードの予備が出る。** 行が増えたら自動で切り替わるよう、
  キーだけ先に書いておいてよい（現在そうしているものは「7-1」を参照）。

### 7-1. まだシートに行が無く、コードの文字列で出ているもの

行が追加されれば**コードを触らずに**切り替わる（キーは実装済み）。

| キー | いま出ている文字列 |
| --- | --- |
| `祭壇を離れるボタン` | 祭壇を離れる |
| `村メニューを出るボタン` | 村を出る |
| `図書館の報酬枠見出し` | 貸出カード |
| `「祭壇」説明文1` / `「祭壇」説明文2` | 3枚のカードを捧げれば、1つを選んで獲得可能 ／ 対価の力は与えられた |
| `「絆の巻物」使用時1` / `使用時2` | （現在は「「絆の巻物」使用時」の1行を両方で使用） |
| `オンライン対戦のボタン（カード選択）` / `（待機時）` | 選択完了 X/Y ／ 戦闘待機中 |
| `指輪の「有効化」ボタン` | 有効化（無効化中の指輪をクリックした時。「無効化」「捨てる」「やめる」はシートの行あり） |
