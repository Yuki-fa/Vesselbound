# データ・文言

シート駆動の文言とデータ反映規則を記録する。カードデータ、効果文、画面文言、ローカル内蔵CSVを変更するときに読むこと。

## 効果文の表示（魔導板・商店・コレクション）

キャラクターカードの説明文は、どの画面でも `_rawSubstitutedDesc(card)` を渡すこと。
生の `card.desc` を渡すと、召喚体の注釈（「結界1を持つ3/1の「黄ナイトキャット」」）・
Grade置換・自己名の除去が抜け、**同じカードなのに商店と魔導板で説明が食い違う**
（ケットシー、2026-09-22）。魔導板は reward.js、商店は render.js が描く。

色の字（赤青緑黄紫黒）を `_injectManaIcons` がアイコンへ置き換えるが、**固有名詞は置き換えない**。
指輪名は `RING_POOL` から引いて守るので、シートへ指輪を足せば自動で守られる。
加えて「色＋の指輪」「黄金」「色＋い瞳」も文字のまま残す（利用者指定 2026-09-22）。

## 報酬カードの抽選（グレードとレアリティ）

唯一の実装は pool.js の `_rewardWeightedPick`。シート「戦闘報酬カード出現率計算式」が正。

「現在のマップ」＝ `G._wave`（1〜5）。**増えるのは祭壇を越えた時だけ**で、マップ内の村・
通常戦・エリートでは変わらない（そちらは `G._waveStage`）。レアリティの「1ステージ進むごと」も
同じ `G._wave` を見る。両者は必ず同じ値を見ること。

**レアリティ枠は動かさない。グレード枠のほうを引き直す**（2026-09-21 利用者指定）。
グレードとレアリティの在庫は偏っている（グレード1にレア5は0枚、グレード4にレア1は0枚）ので、
「枠に無いから近いレアリティへ寄せる」と marginal が崩れる。実測でレア3が14%→20%、
レア5が2%→0.5%になっていた。今はレアリティを固定し、そのレアリティを持つグレード枠だけを
元のグレード比率のまま引き直す。どのグレードにも無い時だけ近いレアリティへ寄せる。

その結果、**レアリティはシートどおりになり、グレードのほうがシートから外れる**
（ステージ1で実測 70/19/8/2.4、シートは 70/15/10/5）。「かつ」で結ばれた2つの比率は、
今のカード在庫では同時には満たせない。レアリティを優先する、が現在の決定。
グレードの体感を変えたい時はシートの数値を動かすこと。

グレード5のカードはシートに1枚も無い（キャラ・強化とも最大4）。`REWARD_MAX_GRADE=4` はそれに合わせてある。

## アイテムはシートに足すだけでは効果が動かない

キャラクター・エンチャント・エネミー・リングは、シートの行がそのままプールへ入る。
アイテムも 2026-09-21 から loader がシート行を `ITEM_POOL` へ追加する（名前・レアリティ・
グレード・効果文・絵 `assets/art/items/I0NN.jpg` はシートが正）。

ただしアイテムの効果は `itemEffectKey` ごとに reward_items.js で実装するもので、
シートには効果キーの列が無い。コード側に無い行は `_noItemEffectImpl` が付き、
**コレクションには出るが入手・購入の抽選には入らない**（`drawItems` が外す）。
読み込み時にコンソールへ警告を出す。

効果を実装したら、pool.js の `ITEM_POOL` へ `itemEffectKey` 付きで追加すること。
名前または No. が一致すればシート行はそちらへ上書きされ、`_noItemEffectImpl` は付かない。

## 7. 画面の文言はシートから引く

施設の会話は「会話メッセージ」シートを使う。街見出しの下の「場面／対象／台詞1／対象／台詞2／対象／台詞3／対象／ゴールド不足時台詞／対象／再訪時台詞」を `loader.js` が列名で読み、`map.js` が今の街の場面だけを選ぶ。台詞2の「・」で始まる行が選択肢で、料金とライフ回復量はその文中の数値を読む。シート更新時は `python3 tools/update_local_xlsx_data.py talk` で内蔵CSVを更新する。

**画面に出る固定の文言（見出し・ボタン・指示文・説明文）は
「テキストメッセージ」シートが唯一の出どころ。** コード側の文字列は
**シートを読めなかった時の予備**としてだけ持つ。新しい文言を足す時も必ずこの形にする。

| 出し方 | 使うもの | 置き場 |
| --- | --- | --- |
| JSからDOMへ書く | `textMessage(場面, 予備)` | `js/data/loader.js` |
| ボタン・見出しのラベル | `_uiLabel(場面, 予備)`（`textMessage` の薄い包み） | `js/engine/reward.js` |
| 決まった位置の枠見出し | `applySheetDomTitles()`（`SHEET_DOM_TITLES` に足す） | `js/engine/main.js` |
| CSSの `content:` | `applySheetCssTexts()` がカスタムプロパティへ入れ、`content:var(--title-xxx,"予備")` で読む | `js/engine/main.js` ＋ `index.html` |

- **シートの「場面」列は改行を含むことがある**
  （例：「編成、ショップ画面「旅の進捗」内」＋改行＋「通常時」）。
  `textMessage()` が空白・改行を無視して突き合わせるので、呼び出し側は1行で書いてよい。
- **本文の中の記号はシートの書式をそのまま使う。**
  `〜`＝塔の名前、`X`／`Y`＝数値（`_journeyCountdownHtml()`／オンラインの「選択完了 X/Y」）。
  コード側で「〜まであと」などの文をつなぎ直さない。
- 2段階選ぶアイテムの指示文は「「◯◯」使用時1」「使用時2」。1段階なら「「◯◯」使用時」。
  引き当ては `_itemUsePromptText()` が唯一の実装。
- **シートに行が無い文言はコードの予備が出る。** 行が増えたら自動で切り替わるよう、
  キーだけ先に書いておいてよい（現在そうしているものは「7-1」を参照）。

### 7-1. シートを読んでいない文言の監査（2026-10-29 全面移行）

監査は `node tools/balance_sim/hardcoded_text_audit_1027.js`（`prototype` で実行。結果は同じフォルダの
`HARDCODED_TEXT_1027.md`）。2026-10-29 に主一覧の文言をテキストメッセージシートへ移した（利用者指定：
ゲーム内の全てのテキストを Vesselbound_data.xlsx から読む）。シートの末尾に区分「読み上げラベル」
（aria-label 用）と「デバッグ」（デバッグモードのボタン等）を足した。

- **HTMLの固定の文言・aria-label・title** は `SHEET_DOM_TITLES`（`attr` で属性も入れる）。
  実行時に必ず書き換わる仮の文言（ゲームオーバーの結果、編成画面の左上、クエスト枠、提示カード、
  出発・魔導板の使い方のボタン、言語の選択肢）はHTMLを空にし、各画面の同期処理だけがシートから入れる。
  言語を変えると `applySheetDomTitles()` が走り直すので、状態で文言が変わる要素を `SHEET_DOM_TITLES` に入れない
  （入れると今の状態と違う文言へ戻る）。状態で変わるボタンは同期処理（`_syncBoardCardVisibilityLabel` 等）を呼ぶ。
- **設定表の文言は `[場面, 予備]` の組**で持ち、表示の時に引く（`BLESSING_FLAME_CONFIG.text`・`RUN_LEVEL_CONFIG`・
  `TOWER_BOON_CONFIG.text`・`COLLECTION_TEXTS`）。数値は本文の `X`（2つ目は `Y`）へ差し込む。
- **シートの本文に数字を差し込むだけの置換**（「（あと X 戦）」「（状態異常：毒N）」「Nマナ：」、旧祝福の
  「(X×N)ダメージ」）は、語を正規表現で捕まえて本文のまま戻す。コードに語を書き直さない。
- 付与キーワードの説明（「毒牙」「衝撃」「生命吸収」付与時の説明文）は、キーワードシートの効果文と言い回しが違う。
  移行時に表示を変えないよう、今の文言のままテキストメッセージシートへ移した（加護だけはキーワードシートと同文なのでそちらを読む）。
  揃えるかは利用者判断。

意図して残すもの（監査の主一覧に残る。シートへ移さない）：

| 種類 | 例・場所 | 理由 |
| --- | --- | --- |
| カード・指輪・キーワードの名前 | core.js の召喚体（青シャドウ等）、enemy.js の予備の敵、migrations.js の旧セーブ変換、render_card_display.js のキーワード名、battle_panel_formation.js の予備名「召喚」、reward.js の「封印N」 | キャラクター／指輪／キーワードシートの行を引く識別子。文言ではない |
| 内部の目印 | 「キーワード：」行、マナ・血アイコンの alt、core.js の「マナ：」 | 「キーワード：」は `_formatPreviewHtml` が見分けてラベルを出さない。alt は `_stripIconsForMatch` が文字へ戻して照合する。シートで変えると壊れる |
| 施設の識別名 | arena.js の「闘技場」、`BLESSING_FLAME_CONFIG.name` | 画面の名前は `villageFacilityLabelText` がシート（街／塔「◯◯」ボタン）から引く |
| 別シートで上書きする初期定義 | map.js の `MAP_PANEL_POWERS` | 魔導板強化シートが名前・効果を上書きする |
| 画面に出ないエラー | run_save.js・migrations.js・main.js の `Error` | 画面にはエラーコードとシートの文言だけが出る |
| 開発用 | present.js の `PRESENT_DIRECT_LAB_FX` | 演出ラボの一覧名 |
| 旧シートの行名 | 「行商人」見出し・「魔導店」見出し・「魔導店」説明開始 | 改名前のシートでも動くための予備のキー |

`textMessage(場面, 予備)` の予備は残す（シートを読めない時用）。予備がシートと違っても画面にはシートの値が出る。

**ボタン・見出しのキー（2026-09-26 シート整理）**：同じ文言は1行にまとめ、キーは「「X」ボタン」「「X」見出し」の形（例：アイテム・指輪の「捨てる」はどちらも `「捨てる」ボタン`）。旧キー（`アイテムの「使う」ボタン`・`オプションの「戻る」ボタン` など）は使わない。確認窓の OK／キャンセル、クエスト失敗警告・闘技場継戦確認・エラー発生時・データ削除時の見出しもシートから引く。
