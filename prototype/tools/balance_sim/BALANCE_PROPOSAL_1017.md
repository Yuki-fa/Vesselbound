# バランス調整案と新しいエンチャント案（2026-10-17）

自動周回（5方針・計1900周。祝福の座なし／あり）と、固定盤面での1枚ずつの入れ替え比較（ステージ2・3の通常戦とエリート、各5盤面×30戦）から作った案です。
シートは変更していません。数値はすべてシミュレーション上の値で、ブラウザ実機・人のプレイでは確かめていません。

## 結論（先に要点）

1. **難所は2か所に集中**：ステージ2のエリート（2-3）とステージ3のエリート（3-3）。敵の合計値が直前の通常戦の約2.5倍に跳ね、先読みボットでも初戦勝率が23%・4%まで落ちます。
2. **「解放」カードと「Nマナ毎」カードが動いていない**：血とマナが戦闘中にほとんど貯まらず、効果が一度も出ないまま出撃枠を使うだけになっています。カードの数値より仕組み側の問題です。
3. **安いステータス系エンチャントが強すぎる**：内なる大力・大いなる守護・剣技（80G・R1）が、同じ値段帯の平均より大きく上。
4. **祝福の座は「買えない」「祝福1が圧倒的」**：塔で200G＋次の買い物分を持っている訪問は1〜2割だけ。固定盤面では祝福1（能力値3倍）が +38.7pt、祝福4（マナ+1）は +2.8pt と価値の差が大きいです。
5. 新しいエンチャントは **「色の加護」系** と **「不屈の盾」**（味方2体に結界）が、強さ・多様性の両面で有望です。

## 2. 仕組み側の問題

### 2-1. 解放カードが解放されない
固定盤面ではアビス・バロン、アークデーモン、ベヒーモス、フィーンド、オーバーロード、禁断の力が**4場面すべてで一度も解放されず**、平均で勝率 −28〜−38pt（出撃枠を使って戦わないため）。
- 仮エンチャント「死亡：血を2得る」を足しても +1.8pt だけで、血の供給を足すだけでは解決しませんでした。
- **案**：解放に必要な血を下げる（例：ステージ2で届く量に）、または封印中も素の能力値の一部で戦えるようにする。

### 2-2. マナ効果が戦闘中に起動しない
「Nマナ毎」のキャラ（コカトリス、ヴリコラカス、スペクター、ダークワン）や、シルフ・スリープシープが同価格帯の下位。
- コカトリスを「4マナ毎→2マナ毎」、スペクターを「2マナ毎→1マナ毎」にしても**ほぼ変化なし**（効果が出た戦闘が0〜2割）。条件の重さではなく、**戦闘中に入るマナ自体が少ない**のが原因です。
- **案**：開戦時のマナ（野生の力のような効果）を出やすくする、または「Nマナ毎」をステージ開始時に持ち越したマナでも数える。

## 4. 祝福の座（仮）

| 祝福 | 固定盤面の勝率差（盤面のカード全部が祝福を受けた場合） |
|---|---:|
| 1 キャラのATK・HP 3倍 | +38.7pt |
| 2 戦闘修正 ±1 | +21.8pt |
| 3 効果ダメージ 3倍 | +4.3pt |
| 4 マナ +1 | +2.8pt |
| 5 眷属 3倍 | +6.7pt |

- 周回では、塔に着いた時に「200G＋次の街用80G」を持っていたのは全訪問の約1〜2割。祝福は1周あたり最大1回しか買われず、成績はほぼ変わりませんでした（先読み方針のクリア 0%→2%）。
- **案**：初回価格を100Gへ下げる、または初回だけ無料にする。祝福3・4は効果を上げる（ダメージ5倍、マナ+2）か、祝福1を2倍に下げる。
- 不具合を1件直しました：祝福6のボスが魔導店で実装判定に外され、一度も並ばなかった（tower-boon ブランチ de78c91）。

## 5. 新しいエンチャント案（固定盤面で仮に追加して測定）

| 案 | 効果文 | 想定レア | 4場面平均 | 所見 |
|---|---|---|---:|---|
| 不屈の盾 | 死亡：ランダムな味方2体は結界1を得る。 | R3 | **+24.0** | 死者の守護（1体・R2、+14.2）より強い。エリート戦の守りとして有望。R3で釣り合う |
| 紫の加護 | 開戦：全ての紫の味方は熟練1を得る。 | R2 | **+10.3** | 色でそろえる編成の後押し。3-3エリートで +18.7 |
| 緑の加護 | 開戦：全ての緑の味方は熟練1を得る。 | R2 | +6.2 | 同上。盤面の緑が少ないため控えめ |
| 血の盟約 | 死亡：血を2得る。 | R1 | +1.8 | 単体では効かない。解放の見直しと組で検討 |

**多様性の観点で足りないもの**（周回のクリア盤面が少なすぎて型の偏りは測れなかったため、カードの空白から推定）
- **色ごとの専用の後押し**：今は「同じ色」系が共振（攻撃で全同色+1/+1）くらい。上の「色の加護」を5色そろえると、色でそろえる構築が成り立ちます（赤・青・黄版も同じ書式で作れます）。
- **エリート戦（多数の大型敵）向けの守り**：結界を配る・被ダメージを分散する系が少ない。不屈の盾がこの枠。
- **解放・血を回す系**：血を得るカードが少なく、解放カードと献身が死に札。血の盟約は解放の見直しとセットで。
- **戦闘中のマナ供給**：マナ効果のキャラを活かすには、戦闘中に継続してマナが入るエンチャント（例：「負傷：1マナを得る」）が必要。今のコアで読める書式か確認が要ります。

## 6. 再実行の方法（balance-bot ブランチ）
```sh
node tools/balance_sim/run_bot.js --runs 200 --policy all --seed 1 --workers 4 --out tools/balance_sim/out
node tools/balance_sim/fixed_compare.js --workers 4
node tools/balance_sim/fixed_compare.js --override tools/balance_sim/overrides/proposal_1017.json --cards '仮・不屈の盾,仮・紫の加護' --out <出力先>
```
案を試す時は `overrides/*.json` に数値・効果文の変更や仮カードを書き、`--override` で渡します（シートは触りません）。
