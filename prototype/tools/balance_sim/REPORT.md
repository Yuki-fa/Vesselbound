# Vesselbound 個別カード・バランス検証

## 検証条件

- 対象：PANEL_POOL の「キャラクター」かつ _rewardExcluded でないカード（100枚）
- 試行回数：各カード 5 回、固定条件の通常戦闘
- 敵編成：G.floor=5 の generateEnemies()。各カードの試行 j は seed=0x5eed1234+j
- 盤面：メイン盤面1番（前衛中央）に対象カード1枚、指輪・強化・アイテム・地形援軍なし
- 戦闘進行：本番と共通の runBattleCore() で対象・攻撃順・効果を決定。最大手番数は30
- 勝率は「決着（勝敗）がついた試行」のみを母数に計算。打ち切りは敗北に含めず、別途集計する。
