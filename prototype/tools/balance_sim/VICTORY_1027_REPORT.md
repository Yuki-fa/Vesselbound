# 戦闘勝利確定時の停止処理（2026-10-27）

`victory-1027`、作業開始時 `752a7f62f8afc3e44401bda1f5b1d74173c65d72` からの変更。

決着を起こした効果の同時対象・本文内の連続ダメージ・接触と反撃を完了し、後続の効果は共通コアで開始しない。その後に終戦効果を処理する。再生層でイベントを削る仕組みと決着後の専用3倍速を削除した。

## 判断した点

- 敗北・同時全滅の引き分けも同じ停止規則にした。旧コアの勝敗判定・旧専用加速はいずれの陣営の全滅も対象としており、PvEとオンラインの共通ルールを保つため。双方防戦・手数上限による引き分けの成立条件は変更していない。
- 復活・根性・未使用の不死の指輪・解放可能な封印が残る全滅は、新しい停止判定で確定扱いにしない。現在の相互ダメージの後半で倒れた体の根性・復活も完了させる。これによって新しい死亡効果・負傷効果は開始しない。
- 死亡そのものの記録・基本の血・撃破履歴・通常の撃破報酬は残す。死亡によって新たに発動するカードや指輪の効果は止める。
- 通常の速度設定と通常戦闘の自動速度は維持し、勝利確定を理由に速度を掛け足さない。終戦効果はオプションが2倍・3倍でも常に等倍。最後の汎用VFXも完了まで待ってから終戦区間を閉じる。
- 保存なしPvEが開戦後にコアstateを作り直す時も、コアの停止フラグを引き継ぐ。新しい保存対象のGフィールドは追加していない。
- 保存済みイベントと最終状態は組で扱う。既存の計算済み戦闘の表示だけを削ったり、その最終値を維持したままイベントを新ルールへ置き換えたりしない。新規の戦闘計算・setupからの再計算は共通コアの新ルールを使う。

## 結果が変わる範囲

変わるのは、決着を起こした効果の後に開始するはずだった処理。生存者・能力値・資源・永久値が変わるため、それを入力にする終戦効果の対象や結果も変わり得る。

| 場面 | 新しい結果 |
| --- | --- |
| 最後の敵を倒した直後の死亡ダメージ・召喚・奪取・死亡マナ／ゴールド | 新たに発動しない。これらによる戦闘の再開や勝敗の反転がなくなる |
| 決着した接触の反撃で負傷 | 反撃のダメージは残す。負傷バフ・割り込み攻撃・眷属召喚などは開始しない |
| 死亡効果・死亡観測・結界消失の観測で最後の敵を倒した | 現在の効果だけ完了し、次の効果・次の観測者を開始しない |
| 手番冒頭のマナで決着 | 次の毒・通常攻撃へ進まない |
| マナ到達の同時波で決着 | 同じ波の同じ効果は完了し、以後の到達回数・別効果を処理しない |
| 開戦の巻物・指輪・解放効果で決着 | 次のアイテム・指輪・封印解放・開戦効果を開始しない |
| 執念の炎などの撃破時永久強化、渇望などの撃破時の血 | 決着後の新たな誘発分を得ない。決着前の相打ちによる獲得は維持 |
| 魔族の魂の後続発動 | ダメージも永久消耗も発生しない。決着を起こした発動自身の永久消耗は完了 |
| 負傷などによる「このゲーム中」の眷属・報酬強化 | 決着後の後続発動分をラン状態・保存へ書かない |
| 終戦（ユミル・レプラコーン・成長・変化・錬成など） | 生存者と資源を新しい確定状態から読み、通常どおり処理・保存・等倍再生する |

専用の旧コア比較で、最後の敵の死亡ダメージ・召喚・7ゴールド獲得が控えている場面は、旧版の引き分けからp1勝利へ変わり、敵側所持金は257から250になった。

決着しない全カード・強化の435標本は、旧コアとイベント・最終状態が完全一致する固定照合値を確認した。既存の比較検査5,827件（重複標本を含む）では、全滅のない5,568件が結果・全イベント・最終状態・次の乱数まで一致し、残り259件が最初の全滅まで一致した。旧最終値との差分9件は決着後の能力強化（アンタイオス、フォルニョート、ウムブラ等）。この既存標本内では勝敗差は0件で、勝敗差は上記の専用再現で確認している。

## 検査の更新理由

- `victory_1027_regression.js` を新設。30件で、現在の効果の完了・後続停止・終戦・速度・復帰可能な全滅・PvEとオンラインと保存の一致を検査する。実際のSaveRunの計算、圧縮／復元、フレーム再生、終戦の魔導板への永久値書き戻し、所持金、ラン保存／復元も通す。DOMと時計はハーネス。
- `wipe_tail_1020b_regression.js` は、表示側の間引き・加速を期待する検査から、コアが後続イベントを生成しないことと、両再生経路の一致を確かめる検査へ変更。
- `battle_end_fx_1021b_regression.js` の3倍速の期待値を廃止し、終戦の等倍区間を検査。死亡／負傷VFXの検査は生存役を加え、決着前の発動として維持。
- `battle_event`、`effect_audit`、`atk_zero_flee_1019`、`death_1011`、`kenzoku`、`revival_1018`、`fixes_1026b`、`effects_1027`、`ui_1027b` の効果機構の検査は、生存役を加えて決着前の条件を明示した。期待する効果量や発動回数を小さくして通す変更ではない。召喚枠の検査を妨げる生存役は後衛に置いた。
- `sheet_1025b` のケール連鎖は、最後の敵の死亡後に死亡召喚を20波繰り返す期待値から、現在の1波だけで終了し召喚しない期待値へ変更。
- 旧コアとの広範囲比較は `victory_1027_compare.js` に共通化。全滅しなかった標本の完全一致を維持し、最初の全滅以降の旧最終値を新仕様の正解にはしない。決着後の差分を集計する。PvE／オンライン／保存同士の全イベント一致は緩めていない。
- ブラウザ検査 `present_parity.js` の殉教シナリオも、生存役を加えて決着前の封印中の味方への移譲を確かめる形へ変更。`anim_check`・`loop_parity` には旧間引き・専用加速を期待する項目はない。

## 資料とコードの食い違い

- PRESENTATIONの2026-10-22節は「全滅後も処理し専用3倍速」、2026-10-20の追記は `presentMarkBattleTail` 等で合図を省くとしている。今回の最新指定でどちらも廃止した。資料の変更は禁止されているため、そのまま残している。
- PROJECT_MAPの個別VFX指定とPRESENTATIONの古い本文はシートの「VFX/SE」列を指定元としているが、現在のコードは `loader.js` の `CARD_PRESENTATION_FX_CODES` とpresent側の割り当てを使う。PRESENTATIONの2026-10-22追記にはコードへ移した経緯が記載されている。

## 範囲外で確認した既存挙動

不死の指輪で最後の前衛の全滅から3体が出て両陣営が生存へ戻った後、既存の `coreBattleStep` が `next.result` だけを判定し直し `next.stop` を残すため、全体実行が1手で `draw / turn_limit` になる例がある。p1＝ATK1／HP1・不死の指輪、p2＝ATK3／HP200、p2先攻で再現する。作業開始時のコアと同じ結果・イベント・最終状態になることを新規検査で確認した。決着していない間の結果を変えない指定に従い、この別件は変更していない。HISTORYでは該当する記録は見つからず、docs変更禁止のため本報告に記録した。
