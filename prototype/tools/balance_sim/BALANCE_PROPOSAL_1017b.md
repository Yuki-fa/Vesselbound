# バランスの検討・第2回（2026-10-17）

## 結論

1. **組み合わせ候補の第1位は G3 A+E**。平均到達ステージは基準100周の2.58から2.95、3-3初戦勝率は2.0%から35.9%、クリアは2件から12件。順位は今回の同じ種を見て選んだ探索上の順位であり、未知の種での再検証はしていない。
2. **単独案はAとEを優先**。Aは敵の跳ね上がりを抑え、Eは祝福の購入と到達の両方を増やした。Bは解放そのものを改善するが周回成績はほぼ横ばい。C1は2マナ以下の効果を動かすが4マナ勢には届かない。
3. **新ルールでも主な壁は3-3**。基準planner 200周では初戦勝率4.3%。2-3は67.9%まで上がっており、前回の「23%・4%」を現在の基準として使わない。
4. **魔導板の枚数は想定より少ない**。初周・依頼なしの計算上限は祭壇出発時3／5／7／9枚。初期2枚＋ステージ1の通常報酬4枚−指輪代3枚なので、4／6／8／10枚とは最初から1枚違う。実測は合体・消失・見送り等でさらに減る。
5. **DとFは一括採用を急がない**。スケルトンキング通常形とジャックの突出はD後も残る。Fの不屈の盾は固定比較で同条件の平均との差が約+22ptと大きい。クリア率だけで強さを判断しない。

シート、`js/**`、`index.html`、素材は変更していない。以下はすべてシミュレーション上の仮入力の比較。画面・音・人のプレイは未確認。

### 条件と基準

plannerは既存の第2段の係数を固定し、lookaheadと各200周、種4001〜4200。魔導店・敗北時の行商人は通常出現率の3枚を1対1交換する。カード売却・購入なし、祭壇の指輪は3枚を払って必須取得、不足時だけ免除。祝福の座あり。初周のステージ4の塔がゴール。

単独7条件と組み合わせ3条件は計算量のため各100周（4001〜4100）。比較の基準も同じ100種へ切り出す。plannerの再学習はしない。同じ種でも選択が変わると、その後の提示・乱数消費は分岐する。後半の初戦勝率は到達者を母数とし、未到達を敗北で補完しない。

本体の敵生成、魔導板からの編成、戦闘コア、交換、指輪、祝福を使用。途中の表示フレームだけ省く既存の固定比較用computeを実戦にも使用し、基準400周の本体結果・選択・資源を既存の新ルール400周と全JSON照合して一致した。戦闘上限500手と行動上限300は維持。`timeout`は500手で打ち切られた戦闘を含む周回で、ゲームオーバーと区別し、クリア率では未クリアに数える。初戦率でも勝利に数えない。打ち切り後に続けた場合の結果は未推定。
