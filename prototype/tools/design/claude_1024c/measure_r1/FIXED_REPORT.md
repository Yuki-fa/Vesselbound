# 固定盤面によるカード比較

38枚の通常形と0形態の本体合体後、合計38形態・760件のカード×盤面比較。評価は各30サンプル、エンチャントの接続選択は別seedの各30サンプル。6プロセス、比較の壁時計61.16秒。差し替え後の評価22800戦に加え、基準・接続探索・効果除去も実行した。

盤面選定の壁時計133.61秒。実周回の非再戦の開戦直前。JSONLで予備評価し、元seedを完全一致再実行して本体の正式なラン保存対象・開戦アイテムを採取。不足時のみ本体の通常／3枚合体カードを空きマスへ追加。既存カードの数値・方向は維持。

保存済みの標準盤面を維持し、現在の本体で比較を再計算した。選定時勝率は元版の値、比較時勝率は今回の値。盤面選定の元周回は新しいworktreeに含まれない場合がある。

## 方法と解釈

- 出撃中キャラの本体ATK+HP最小、同点はマス番号。元キャラの向きを継承。
- 空きマス全てと、隣接ATK+HP・レア度・マス番号で最弱の既存エンチャント1枚。実際の本体接続を列挙。提示時の向きを固定。
- 独立した接続選択サンプルで勝率→残HP→与ダメージを比較し、別の評価サンプルで差を測定。
- シート基準の通常形（G1を含む全グレード）と本体の3枚合体。シートG2以上をG1へ改変しない。
- コアdamageイベントの敵側amount合計（オーバーキルを含む）。
- coreLivingUnitsが返す行動可能な生存味方のHP合計。封印中は除く。

通常形はシートの基準カードで、G1が中心。固有の出現グレードがG2〜G4のカードも全数を測り、その値をG1へ改変しない。合体は `_tryTripleMergeOnBoard` で実際に3枚を合体させた別形態。合体不可のカードは通常行だけ。標準価格は割引前の本体 `_mapSalePrice`。

盤面は元周回を完全一致再実行して、本体の正式なラン保存対象と使用済みの開戦アイテムを採取。選定時には独立30サンプルで25〜75%の盤面だけを採用する。選定時と比較時の敵seedは別なので、比較時の基準勝率がその範囲を外れる場合もある。ライフ・所持金・指輪・永続補正・開戦アイテムは各基準盤面内で固定する。購入・施設・次戦への持越しは測らない。

95%区間は敵seedごとに「全盤面の平均勝敗差」を1観測とする対応あり正規近似（平均±1.96×標準誤差）。同じ敵を盤面間でも使うため、5盤面×30戦を独立な150敵とは数えず、30個の独立seedで誤差を測る。接続を選ぶseedと報告するseedを分け、選択による上振れを抑える。これは試した固定盤面と敵分布での試行誤差であり、未検証盤面への一般化や全カード同時比較の多重性は補正しない。区間が0をまたぐ差は偶然の範囲を含む。

戦闘は本体の魔導板→formation→コアを通す。比較を速くするため、SaveRun.computeBattleのソースから途中の表示フレーム保存を省き、不変の召喚定義を共有した検査専用の受け口を使う。戦闘ステップ・対象・数値・撃破ゴールド処理は原文のまま。本体の500手上限を守る。元のcomputeBattleとの全イベント・最終状態一致を自己テストする。本体ファイルと既存周回ツールは変更しない。

overrideは読み込んだプールへ適用し、仮追加は表の「仮」で区別する。固定盤面の保存済みカード自体は変更せず、比較対象と召喚定義に反映する。既存カードの合体効果変更には周回ボットと同じくmergedDesc指定が必要。解釈できない文・条件未成立はイベント変化なしの候補として出る。

封印持ちの負の差には、解放に必要な血が足りず参加できない場合も含む。解放後だけの性能ではない。色・マナ・召喚数などの条件も固定盤面に依存するため、順位はこの盤面群での調整候補として読む。

## 未確認・限界

- 5盤面/場面の構成と、提示時の1組のエンチャント方向に依存する。他の向き・構成全般の順位を保証しない。
- 接続先別の相性表は探索用サンプルの値で、全盤面平均の主表だけが独立評価用サンプル。
- 発動変化なしは実装漏れと条件未成立を区別できない。将来の戦闘向け経済効果・アイテム取得の価値も勝率差には出ない。
- イベント変化があっても本文全ての解釈を保証しない。既存名のカードには名前から起動する互換効果もある。
- 固定盤面への追加カードには実際の入手費用や合体素材集めを課していない。
